First release. `freetranscribe` is open tooling from [FreeTranscribe.org](https://freetranscribe.org/), and this version has one module, `freetranscribe.parakeet`, for decoding [NVIDIA Parakeet](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) models in [NeMo](https://github.com/NVIDIA-NeMo/Speech).

- `freetranscribe transcribe recording.wav` transcribes audio with a Parakeet model. It defaults to [freetranscribe/parakeet-ft-v1](https://huggingface.co/freetranscribe/parakeet-ft-v1) and takes any `.nemo` file or Hugging Face model id through `--model`, including `nvidia/parakeet-tdt-0.6b-v3`.
- Long recordings are decoded with 256-frame local attention, cut at pauses into pieces of at most 90 seconds, and decoded with 5 seconds of overlap on each side. `--max-seconds`, `--overlap-seconds` and `--batch-size` change that.
- `--json` prints the text, each word's start and end time, and the pieces the recording was cut into.
- From Python, `from freetranscribe import parakeet` gives `parakeet.load_model` and `parakeet.transcribe`.

Install the command with `uv tool install "freetranscribe[nemo]"`, or add `freetranscribe[nemo]` to a project with `uv add` or `pip install`. The `nemo` extra pulls in NeMo and PyTorch.
